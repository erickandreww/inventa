# Inventa

Inventa is a full-stack inventory and business management application built as an individual portfolio project.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM

## Features

Planned V1 features:

- Authentication
- Dashboard
- Product management
- Category management
- Stock control
- Stock movement history
- Low-stock alerts
- Search and filters

## Development

```bash
pnpm install
pnpm run dev
